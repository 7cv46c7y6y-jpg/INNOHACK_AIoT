# 입력 항목과 서식 칸 대응표

칸 위치는 `표 번호 / 행 / 열` (0부터 셈)이다. 원본 서식을 HWPX로 바꾼 `forms_tpl/` 기준이며, 코드는 `core/forms/`에 있다.
✕ 표시는 앱이 일부러 채우지 않는 칸이다.

## ① 자연재난 피해신고서 (`f01_disaster_report.py`)

| 피해 발생 위치 (①~⑤ 공통) | 0/15/4 | 어장 위치 + "(품종: …)" |
| 피해시설명 ① | 0/16/4 | "해상가두리" (규칙 파일) |
| 총면적 ① | 0/17/4 | 면허 면적(ha) |
| 면허·허가·등록 번호 ① | 0/18/4 | 면허번호 |
| 피해물량 신고 ① | 0/19/4 | 이번 피해량(마리) |
| 피해물량 확정, 피해 구분, 피해 원인 | 0/20~22/*, 0/30~32/* | ✕ 회색 칸 (공무원) |
| 융자신청 여부 ① | 0/23/4 | 융자 신청 체크 |
| 국·공유재산 사용·대부 여부 ① | 0/24/4 | 해당 체크 |
| 시설 ②~⑩ | 0/16~34/* | 시연 범위 밖 (시설 1곳) |

시설별 칸은 폭이 약 2.4cm라 "품종 + 마리 수"는 6pt로 줄여도 한 줄에 들어가지 않는다. 그래서 피해물량에는 마리 수만 적고 품종은 피해 발생 위치 칸에 적는다 (`config/form_rules.json`).
